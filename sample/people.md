# Team & Ownership

Quick map of who owns what — decisions and actions reference these people.

| Person | Role | Owns |
|---|---|---|
| Sarah | Payments platform lead | Billing provider migration, payments service, settlement |
| Mike | Security engineer | Security reviews, transfer security, access controls |
| Elena | Product designer | Payments UX, empty states, mobile wallet flows |
| Priya | QA lead | Test coverage, release sign-off, regression suites |
| Dev | Platform/infra engineer | Infrastructure, queue providers, deployment pipelines |
| Aisha | Product manager | Roadmap, PRD, stakeholder alignment |

## Notes

- Escalation for security-sensitive changes: Mike must sign off before merge.
- Sarah is the final approver for anything touching settlement or money movement.
- Priya owns the definition of done for release (coverage gate, smoke suite).
- Aisha is the point of contact for external partners (e.g. the wallet vendor).
