## Process lessons (cost real time this session)

- `$ErrorActionPreference = "Stop"` + a native command writing to stderr (git,
  chrome) aborts the whole script — the tag push was skipped that way once.
  Drop the Stop preference or redirect `2>$null`.
- PowerShell **variable capture** of chrome's stdout is empty (`$x = & chrome
  --dump-dom ...`), while a pipeline to a file works, and chrome forwards
  arguments to an already-running instance ("Opening in existing browser
  session") so the dump silently produces nothing. Use `| Out-File` or node's
  `execFileSync`.
- Killing every `chrome.exe` also closes the owner's browser — filter by start
  time instead.
- Windows Chrome enforces a ~482px minimum window, so a real 390px viewport
  needs a same-origin iframe (see the temp harnesses used for the a11y and
  density numbers — they are throwaway, not committed).
