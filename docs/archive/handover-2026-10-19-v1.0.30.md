## Diagnosis notes (field report, kept for the record)

- The `suspect` flag on clean-looking text is read-time (trips on stored
  text now) — either residual shredding or a detector false positive;
  unresolvable without the corpus. It currently helps (suspect items get
  flat-leg rescue via R39.8), so not worth chasing blind.
- Ghost sections on already-indexed items need a force re-sync
  (Reclassify) — incremental sync skips fingerprint-unchanged files, so
  R39.9/R40.3 only apply at chunk time. Verified `force_reclassify`
  empties the fingerprint map and re-chunks everything.
- Vocabulary gap (cancellation vs Reversal headings) + 8-cut crowding is
  the remaining RFP surfacing problem — R40.4/R40.5 territory, not in
  this release. 1.0.30 gives the tools (working `limit`, truthful
  scores), not the surfacing itself.
- CSRF on search is covered by the search skill; `rest-api.md` is the
  connector guide, not the API reference — no docs gap on our side.
