### Windows test-suite fix (the "it hangs" problem — pre-existing, root-caused)

The full suite took 10+ min / appeared hung. Root cause: **Windows does not
RST closed localhost ports** — every dead-port connect waits the full connect
timeout, twice (IPv6 ::1 + IPv4). macOS fails instantly, so the author's
"~18s suite" claim never held on Windows:

- `status.py` Ollama probes: `connect=2.0` → ~4.2s per lifespan × 95 tests.
- `RetryClient` hardcoded `connect=5.0` (`http.py`) → ~2s per classifier/
  embed call (3–4 per sync × ~25 syncs).
- Fix: `ANCHOR_HTTP_CONNECT_TIMEOUT` (default 2.0) read by `RetryClient` and
  the status probes; conftest sets `0.2`. Suite: 10+ min → **2:34, 95 passed**.
- Rule: never hardcode `httpx.Timeout(connect=...)` per-call again.

### Pre-existing broken test fixed

`test_project_scopes_qa_results` asserted `"/alpha/" in source_ref` — on

spanning assertion (the three docs are byte-identical; tie-order is arbitrary).
The scoped assertions keep requiring exact inclusion/exclusion.
