# AnchorCore 1.0.33

Scoped search that stays in scope, Jira descriptions and comments
finally indexed, cleaner document text, and access protection that
denies by default.

## Highlights

- **Project searches stay in their project.** Scoped search and the
  public Q&A surface no longer leak results from excluded projects —
  filename matches included. Scope is now enforced at every level of
  the search pipeline, with a final check that drops anything that
  slips through.
- **Jira descriptions and comments are indexed.** Jira's API returns
  rich text as structured JSON that AnchorCore previously skipped, so
  only summaries, statuses, and assignees were searchable. Issue text
  and comments now index fully (headings, lists, tables, mentions,
  status labels, smart-link URLs). Re-sync your Jira sources to pick
  up the newly visible text.
- **Cleaner document text.** Running headers and footers (document
  titles, page numbers) are stripped at page boundaries, so snippets
  read cleanly and junk matches disappear. Section detection improved
  too: part headers in all caps, numbered sections, and tiny fragments
  that now merge into readable chunks instead of one-line orphans.
- **Citations carry accurate line numbers.** Every chunk now reports
  the line range of its own section, so citations point at the right
  lines in multi-section files.
- **Better results with nomic embeddings.** `nomic-embed-text` inputs
  now carry the instruction prefixes the model expects
  (`search_query:` / `search_document:`), fixing a known recall loss.
  A new count check also turns a silent vector misalignment into a
  loud error. Force re-sync refreshes older vectors with prefixes.

## Fixed

- **Documents mentioning a "sandbox" are no longer mistaken for test
  fixtures.** Environment detection now needs two distinct weak markers
  (`sandbox`, `staging`) or one strong marker (`testdata`, `mock`,
  `fixture`) in a document's opening words before treating it as a test
  file, so ordinary prose stays ranked with live documents.
- **Slow answers could hang indefinitely.** Answer generation is now
  bounded by the existing answer-timeout setting (default 120 s), and
  oversized contexts are capped before they reach the model. Agent
  answers through MCP get their own 180 s hop budget
  (`ANCHOR_MCP_ASK_TIMEOUT`) so slow answers don't die at the proxy.
- **Access protection closed its gaps.** With sign-in enabled, only
  the app shell, health check, and sign-in pages are reachable without
  a token — every other route, including data APIs previously treated
  as app pages, now requires it. Binding to the LAN without
  authentication refuses to boot unless you explicitly opt out
  (`ANCHOR_LAN_NO_AUTH=1` for personal use; the Team image stays
  strict).

## Upgrade notes

- No database migration in this release. No settings changes.
- **Jira users:** re-sync Jira sources once to index descriptions and
  comments that were previously skipped.
- **nomic-embed-text users:** existing vectors stay as-is until a
  force re-sync refreshes them with instruction prefixes.
- **Serving on the LAN without sign-in:** the server now refuses to
  bind `0.0.0.0` without authentication. Set `ANCHOR_LAN_NO_AUTH=1`
  to keep the old behavior on a trusted network, or enable sign-in.
