# AnchorCore 1.2.1

A small correctness fix for the model status banner: it no longer cries
wolf when your answers come from an AI agent or a cloud model.

## Fixed

- **No more false "Ollama is offline" alarm.** The red banner used to
  claim classification had degraded and answers would stay basic whenever
  Ollama was down — even when your AI agent or cloud model was composing
  answers just fine. The banner now reports only what is actually down:
  when your answers are covered it says so, and mentions only that
  search stays keyword-only until Ollama is back. When cloud models
  cover search too, it stays silent.

## Upgrade notes

- No database migrations and no setting changes. Use the 1.2.1 download
  — the app embeds its interface at build time, so older builds still
  show the old banner.
