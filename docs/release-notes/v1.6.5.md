# AnchorCore 1.6.5

The Entities tab is now **Records**, a plain list of your decisions,
actions and glossary. The search skill also gets better at telling "the
app is closed" from "my sandbox is blocking it".

## Highlights

- **Records replaces Entities.** The tab opens on Decisions and also shows
  Actions and the Glossary. You can **Dispute…** a decision or action that
  is wrong (a reason is required, and the history is kept) and **Restore**
  it later. A **Disputed** filter shows the ones you've set aside. A
  disputed record drops out of the Decisions and Actions lists and out of
  what agents get from the `decisions` and `actions` tools.

## Fixed

- **The search skill no longer tells you to open an app that is already
  open.** When an agent runs in a sandbox (Claude Code, for example), a
  blocked call to AnchorCore looks just like a closed app, so the skill
  always said "open AnchorCore". It now checks whether the app is
  actually running. If it is, the skill asks once: "OK to run ask-docs
  outside the sandbox for this session?" It only leaves the sandbox if you
  say yes. If you say no, it gives you the command to run yourself.
- **The skill speaks in its own name.** Its messages use the name it was
  installed under (for example "kb is running on this computer, but my
  sandbox blocks local network calls"), not "AnchorCore". When your company
  hosts the server, a failed call points you to your network or to
  whoever runs it, not to an app on your computer.

## Upgrade notes

- **"Looks right" is gone.** Marking a record as looking right never
  changed any answer: records are used unless they are stale or
  disputed. The review queue, its confidence badges and its "New / In
  answers" labels went with it. Nothing in your library changes. The
  entity and review endpoints stay available for REST and MCP callers.
- **Refresh the installed skill to get the new sandbox step.** The skill
  is a file in your agent's skills folder, so updating the app doesn't
  change it. In the System tab, click **Install…** on the Ask docs skill
  and confirm, keeping the same name or choosing a new one.
