# AnchorCore 1.0.23

Bug-fix release about answer trust: citations always say where they came
from, and vector search can no longer silently drop out.

## Fixed

- **Answer citations now always name their file.** Short entity summaries
  used to come back without a path or title, so there was no way to tell
  which file they came from. Every citation now carries the file path and
  item title (also via the MCP `ask` tool).
- **Vector search no longer silently returns nothing when its index is out
  of sync.** If the fast index holds no rows while the corpus has
  embeddings, the query now falls back to a full scan instead of ranking on
  keywords alone.
- **Embedding backlog after restart drains faster.** When Ollama isn't up
  yet at boot, the backfill retries every minute for 5 minutes instead of
  waiting the full 15-minute interval with chunks pending.
- **Log banner showed a stale version after upgrades.** Each start now
  appends a fresh `AnchorCore Rust … started` line, matching
  `/system/status`.

## Upgrade notes

- No migrations, no config changes, no action needed. Restart on the new
  binary; anything pending embeds within a few minutes of Ollama being up.
