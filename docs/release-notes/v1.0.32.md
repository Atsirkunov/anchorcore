# AnchorCore 1.0.32

A single fix: Linear syncs are working again.

## Fixed

- **Linear syncs failed before fetching anything.** The issues query
  sent to Linear's API carried a stray escape sequence, so Linear
  rejected it as malformed and the sync returned no issues. The query
  builder now emits clean GraphQL and escapes team names safely, with
  regression tests covering paging, incremental sync, and special
  characters in team names.

## Upgrade notes

- No migration, no settings changes. Just sync your Linear source
  again — no need to re-enter the API key.
