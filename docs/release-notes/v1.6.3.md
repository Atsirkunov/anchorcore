# AnchorCore 1.6.3

The Mac app is now notarized by Apple, so it opens with a plain
double-click. Upgrades show what they are doing instead of going quiet,
semantic search is several times faster on big libraries, and you decide
where Sensitive content may go, one switch per destination.

## Highlights

- **Opens like any other Mac app.** The macOS download is now signed with
  a Developer ID and notarized by Apple: open the DMG, drag AnchorCore to
  Applications, double-click. No more trip to System Settings → Privacy &
  Security → Open Anyway.
- **Database upgrades you can watch.** When a new version needs to update
  your library, AnchorCore now opens straight away and shows an upgrade
  screen with the current step and a progress bar, and the menu-bar icon
  says it is upgrading. Before, a large library could sit silent for
  minutes with no window and no icon. Before it starts, AnchorCore checks
  there is enough free disk space and refuses, without touching anything,
  if there is not. Agents asking during an upgrade are told to wait and
  retry rather than seeing "not running".
- **If an upgrade fails, you see why.** AnchorCore keeps running and shows
  the error in plain words, what state your data is in, where the log is,
  and a copy-for-support button. Each upgrade step is saved on its own, so
  the next start resumes where it stopped.
- **Faster semantic search on big libraries.** The vector search reads far
  less data per query: about 4× faster on a 50,000-chunk library
  (340 → 88 ms in our measurement). Results are identical.
- **Choose where Sensitive content may go.** Settings → **Sensitive
  sources** has one switch for each place it could leave this computer: a
  cloud embedding provider, a cloud answer provider, and AI agents
  connected over MCP or the skill. All are off by default, turning one on
  is recorded, and each source row says whether its content stays "local
  only" or is "also sent to" a named host. Local providers (the built-in
  embedder, Ollama on this machine) need no switch. If you change a
  provider's address, its switch turns off until you confirm again.

## Upgrade notes

- **AI agents and Sensitive sources: check one switch.** Agents used to be
  allowed to read Sensitive content automatically whenever your answer
  model was a local Ollama. They no longer are: an agent that reads
  Sensitive documents now gets "gated" until you turn on **Settings →
  Sensitive sources → AI agents**. The AnchorCore app itself always shows
  everything.
- **Admins:** `ANCHOR_CLOUD_TRUST` and `ANCHOR_TRUSTED_PROVIDERS` still
  work and show in the card as "set by environment".
- **No database changes** in this release; it starts as fast as 1.6.2.
- **Older downloads** (1.6.2 and earlier) were not notarized; if you open
  one, macOS still asks for Open Anyway once.
