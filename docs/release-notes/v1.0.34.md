# AnchorCore 1.0.34

A single fix: personal-edition containers boot again.

## Fixed

- **The 1.0.33 access-protection gate refused to start in Docker.**
  Binding `0.0.0.0` without sign-in is now a boot error on bare metal,
  but inside a container that address is the only bind that reaches the
  host's port mapping — so every personal-edition container exited
  immediately. Containers now start with a loud warning instead,
  pointing at the host-side control (`-p 127.0.0.1:<port>:8000` keeps
  the server off the LAN). Bare-metal behavior is unchanged, and Team
  edition still refuses to bind without authentication anywhere.

## Upgrade notes

- No migration, no settings changes. If you pinned the Team image to
  1.0.33 and run it as personal edition, pull 1.0.34.
