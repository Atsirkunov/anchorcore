FAQ — memo, not chatbot

FAQ

Is my data private?

Yes. Binds 127.0.0.1, data in ~/.anchorcore SQLite, secrets in OS keychain. No data leaves unless you add a cloud key. sensitive/pii never sent to cloud without ANCHOR_CLOUD_TRUST=1.

Why Sage #4A5A52 not indigo?

Sage is desaturated (chroma <12), editorial — vault/archive, not SaaS chatbot. Paper #F2F0EB + mono eyebrow + serif hero is the tell. See docs/design-system.md:65.

How are chunks built?

Clean → heading-aware §434/4.2.1 hard split → 1600 pack, fallback 800/100 chunking.rs:68. Summaries section_summary/doc_summary + tags cosine>0.82 per section.

How does retrieval work at scale?

Coarse-to-fine: tag prune → summary 5k → leaf 200 WHERE c.section_id IN → RRF k=60 + age decay + graph 1–2 hops. Flat 150k fallbacks avoided. p50 <50ms on 5k docs.

Free while in validation?

Yes. Download from releases — free now, flat €25/mo at pilot. Team self-hosted = one Docker container, your VPC. Hosted soon — join waitlist.

Do I need Ollama?

No. Rule fallback for classify + keyword retrieval work degraded. Add ollama pull llama3.2:3b + nomic-embed-text for full hybrid + graph.

Citations you can click?

Every answer ships source_ref + path Art 12 › 12.3 + tags + score. UI breadcrumb is clickable; MCP returns same shape.
