60-second demo

  1. Connect sample/ (10 files → 47 entities) or data/business-scale (813 docs → 964 entities).
  2. Ask: What was decided about security transfers, and why? → cited PRD v3 §4.2.
  3. Follow-up: show the movements for it → security-transfers-spec.md steps 1–6.
  4. Ask: Who owns billing migration? → Sarah + graph supersedes.

Run: cargo run -p anchorcore -- --port 8000 then http://127.0.0.1:8000 → Sources → Local folder → sample → Sync → Ask. Or headless: ANCHOR_BACKEND_URL=http://127.0.0.1:8000 cargo run -p anchorcore --bin anchorcore-mcp → search/ask without browser.
