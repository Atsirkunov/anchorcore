FAQ

Is my data private?

Yes. Binds 127.0.0.1, data in ~/.anchorcore SQLite, secrets in OS keychain. sensitive/pii never goes to unlisted providers — allowlist them in ANCHOR_TRUSTED_PROVIDERS or set ANCHOR_CLOUD_TRUST=1.

How are chunks built?

Clean → heading-aware §434/4.2.1 hard split → 1600 pack, fallback 800/100. Summaries section_summary/doc_summary + tags cosine>0.82 per section.

How does retrieval work at scale?

Coarse-to-fine: tag prune → summary 5k → leaf 200 WHERE c.section_id IN → RRF k=60 + age decay + graph 1–2 hops. Flat 150k fallbacks avoided. p50 <50ms on 5k docs.

Is it free?

Personal local app — free. Team self-hosted (one Docker container, your VPC) is a one-time platform license, perpetual including a year of support and updates. Hosted is coming soon — join the waitlist.

Do I need Ollama?

No. Rule fallback for classify + keyword retrieval work degraded. Add ollama pull llama3.2:3b + nomic-embed-text for full hybrid + graph.

Citations you can click?

Every answer ships source_ref + path Art 12 › 12.3 + tags + score. UI breadcrumb is clickable; MCP returns same shape.

How is this different from NotebookLM or ChatGPT file search?

Those are cloud-only uploads. AnchorCore is local-first and self-hostable, connects to Jira, Linear and folders — not just uploads — and gates sensitive sources per your model policy (ANCHOR_TRUSTED_PROVIDERS).
