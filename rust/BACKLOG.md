### Phase 35 — People-driven PII: manual doc-level marking, deprecate the auto machinery (owner decision, 2026-10-12) — 1 shipped / 2 open

> Owner decision, supersedes the earlier close-the-bypass framing: PII is handled by people. Background: the 2026-10-12 bypass report found (1) entity/item reads gate only on self-asserted `?gate=provider` (`entities.rs:57` early-returns open without it; same in `items.rs`, `related`, `context`) — honor-system theater on the exact path it exists to protect; (2) `/qa` + `/qa/search` gate against the server's configured provider instead of the actual byte consumer. The auto machinery also has measured costs (`flag_pii_for_item` rescan: 28 s on one PDF per R30.5) and regex detection leaks by nature, so it promised what it couldn't hold.
